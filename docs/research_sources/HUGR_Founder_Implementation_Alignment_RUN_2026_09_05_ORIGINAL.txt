MOUSTACHE'S CURRENT RECONSTRUCTION
1. Original HUGR

HUGR began as a deliberately opinionated, human-centred dysregulation/awareness system.

Its core intuition was not simply:

detect state → label person → intervene.

It was closer to:

learn enough about this individual's changing physiology and context that the system may sometimes notice something useful early enough to offer a private, minimal “tap on the shoulder.”

Four-state language, tolerance-window concepts, dysregulation, haptics, check-ins and related clinical constructs may therefore be legitimate HUGR application hypotheses/design choices.

Their presence is not automatically ontology contamination.

2. What HUGR is trying to learn

Current hypothesis:

HUGR seeks useful structure in an individual's longitudinal physiological trajectory, under uncertainty and context, rather than assuming that a sensor snapshot directly reveals a person's psychological state or identity.

The system may use categories or decision boundaries when useful.

But those categories remain models/instruments, not declarations about what the person is.

3. Meaning

Current principle:

Preserve evidence before collapsing it into meaning.

Observations, identity, clocks, quality, missingness, provenance, transformations, baselines, deviations, uncertainty and competing explanations should survive as far upstream as practicable.

Human meaning, clinical interpretation and application-specific constructs should enter where purpose requires them, not silently at acquisition.

This does not require original HUGR to become clinically neutral.

4. Learning

“Learning Neil” contains several separate propositions:

remember Neil → model Neil personally → predict something about Neil → discover when prediction is wrong → update eligible machinery → demonstrate later prospective improvement.

Stored history is not by itself learning.

Adaptive thresholds/baselines are adaptation.

A model changing parameters is computational learning/adaptation.

The strongest HUGR claim requires:

qualified evidence → prediction using only then-available information → immutable freeze → future outcome → predefined score/error → eligible update → later prospective comparison.

The 22 August recovery appears to have implemented a candidate form of this loop; its physiological usefulness remains unproved. The archaeology report already records that prospective benefit remains unestablished.

5. Query/action hypothesis

The original tap may survive, but its role may be broader than “intervention.”

When an uncertain trajectory contains an informative ambiguity, HUGR may eventually choose among:

tap / ask / explain / wait / abstain / remain silent.

A question may sometimes be an information-seeking action:

observe → preserve uncertainty → identify useful ambiguity → decide whether/when to query → obtain human context/outcome → score → update.

Whether this is useful is a HYPOTHESIS, not a demonstrated capability.

6. Human authority

The person has privileged authority over:

lived experience, goals, preferences, burden, perceived meaning and self-report.

The person does not thereby establish:

sensor validity, physiological causality, model calibration or universal scientific meaning.

Conversely, the model's physiological inference does not overrule the person's meaning.

7. Original HUGR versus possible HUGR Labs

Current hypothesis only:

Original HUGR may remain an opinionated dysregulation application.

Some lower machinery may prove reusable:

qualified observations → transformations → personalized comparators/baselines → uncertain temporal inference → bounded prediction/question → outcome → scoring → eligible learning.

That possible reusable substrate is currently a HUGR Labs hypothesis.

Technical reuse does not establish scientific utility, market value or platform generality. The current archaeology explicitly preserves that boundary.
