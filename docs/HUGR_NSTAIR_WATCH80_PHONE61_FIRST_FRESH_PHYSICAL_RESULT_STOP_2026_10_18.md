## Bounded read-only source interpretation — not a repair

The failed characteristic `99999999-9999-4999-8999-999999999999` is the **Watch run-receipt bridge**, used for paged receipt writes/reads (`lib/watchRunReceiptTransport.ts:3`; `lib/bluetooth.ts:834–836`). It is not the canonical source-control characteristic (`88888888…`, `lib/bluetooth.ts:85`). The successfully displayed source resume is written to source control at `lib/bluetooth.ts:995–1005`. A later receipt polling/observation write can therefore fail after source subscription/resume.

The displayed “Source integrity failed” literal can be set by source-ingestor error or source-journal subscription-error callbacks (`lib/bluetooth.ts:944–951`, `975–983`). These persist `PHONE_SOURCE_INTEGRITY_FAILED` and cancel the connection. Source-ingestor failures include malformed/unknown frames, native append/session mismatch, manifest-verification failure and selected-session mismatch (`lib/build45SourceIngestion.ts:104–125`, `145–164`); they are not restricted to a canonical SHA-256 mismatch. Lifecycle persistence errors can also mark source-integrity eligibility false (`lib/bluetooth.ts:260–271`). The transport model renders the generic integrity label whenever that eligibility is false (`lib/build46TransportStatus.ts:62–76`).

A plain disconnect has a separate classification and does not itself set the source-integrity literal (`lib/bluetooth.ts:787–804`; `lib/build46TransportStatus.ts:74`). Outer connection/receipt-write failures use the connection-failed catch (`lib/bluetooth.ts:1367–1386`). Thus **the screenshot alone cannot establish the ordering of source rejection, connection cancellation/disconnection and receipt-write failure, or which callback produced the integrity banner**. It proves neither canonical-byte corruption nor that the operator's system reconnect caused the failure. Preserve both the receipt-transport failed boundary and unresolved underlying source/storage/peer-service event rather than replacing them with a single presumed Bluetooth diagnosis.
