## Standing repair

- `scripts/hugr_preserve_mirrors.py` in the controlled repository preflights **both** `Nervahealth/nerva-wearos` and `Nervahealth/nerva-mobile` before publication. It prefers the enabled task integration *only if both* accept an actual unreferenced write. Otherwise it uses the existing stored repository-write login with both injected token variables removed. If neither can write both, it stops publication and requires a checksum-read-back sanitized fallback, not a misleading local-commit success.
- It validates clean local Watch/Phone/control trees, exact expected branch names, first-parent linear ancestry from the last verified bases, unique matching remote Git *tree* in each branch's local history, and changed-path/blob identities. It constructs one remote commit per missing local commit with parent at the current remote branch head, verifies exact resulting tree, checks the remote head is unchanged before its **non-force** ref update, then reads back exact head/tree. It never merges to main, force-pushes, deletes branches or alters device/private evidence. Running without `--apply` is read-only; applying reruns all preflights and stops on conflict/permission failure. The three mirror branches are distinct; preserving one never silently certifies the others. Local commit IDs differ from remote mirror commit IDs because GitHub commit parents differ; exact *tree IDs* prove content equality.
- Focused local unit tests cover injected-token shadow avoidance, both-repository write preflight, fail-closed inaccessible route and foreign remote-tree rejection. The project instruction was also updated and read back, so future Nerva tasks automatically apply this rule without a RUN# reminder or code/token exchange. No secrets are stored in that instruction or this script.
